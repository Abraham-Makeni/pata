## Step 5 — Quick implementation in Windsurf

Paste this prompt into Windsurf:

```
I have a Next.js project called PATA. I need to add images to the app.

1. Create these folders in /public/images/:
   - categories/ (6 images)
   - providers/kevo-cuts/ (8 images)
   - providers/slim-barbers/ (8 images)
   - providers/blade-room/ (8 images)
   - providers/zuri-hair/ (8 images)
   - providers/glam-house/ (8 images)
   - providers/nailhaus/ (8 images)
   - providers/beat-by-adaeze/ (8 images)
   - providers/lense-by-odhis/ (8 images)
   - providers/ink-and-soul/ (8 images)

2. All image paths are already defined in lib/data.ts — filenames must match exactly.

3. I'll drag-and-drop images into each folder. The app uses Next.js <img> tags with 
   onError fallback so the UI works with or without images.

4. After adding images, update next.config.js if needed for image optimisation:
   Replace the contents with:
   
   const nextConfig = {
     images: { unoptimized: true }
   }
   module.exports = nextConfig
```
